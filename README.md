## 这是什么

抖音直播的复盘方法论与配套脚本。

产出四样：

1. **场次数据**：整场核心指标
2. **分钟级曲线**：成交、在线、互动的分时变化
3. **讲解时间轴**：哪个时间点讲了哪个品
4. **复盘结论**：哪段有效、哪段空转、下场改什么

## 核心方法

把「讲解动作」和「成交曲线」放在同一条时间线上对齐。

后台大屏给你的是整场汇总，但问题通常只在其中二十分钟。「GPM 低」是结论不是诊断，要知道为什么低，必须看**哪次讲解没转化成单**。

## 关于账号

**脚本依赖你已登录的浏览器环境**，不自带账号。

第一次用需要在浏览器里登录电商罗盘，之后复用登录态。仓库内不含任何 cookie、账号或店铺数据。

## 已知限制

- 罗盘会改版，DOM 变了脚本要跟着改
- 数据口径以平台为准，结论带核实日期
- 部分指标需要专业版才能看到

## 适用与不适用

**适用**：自己做抖音直播、需要复盘讲解节奏与转化效率的团队。

**不适用**：想看别人直播间怎么做——数据拿不到。
